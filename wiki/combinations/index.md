# 조합과 도킹

## 검토된 조합

- [[coody-10-hub-docking|쿠디 10.0 PRO + 허브쉘터 PRO]] — 도킹 가능 확인, 명목 외곽 계산, 실제 설치 여유 미확인

## 원칙

- `도킹 가능`: 판매페이지나 사용자 확인으로 물리적 연결 호환성이 확인됨.
- `배치 계산 가능`: 연결 방향과 본체 외곽이 확인되어 명목 외곽을 계산할 수 있음.
- `사이트 설치 적합`: 가이라인, 스커트, 팩다운, 차량, 출입 동선을 포함해 실제 설치 가능성이 확인됨.

세 상태는 서로 대체하지 않는다.
