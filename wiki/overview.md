# 프로젝트 개요와 현재 상태

## 목표

겨울 장박용 에어텐트를 제품·모듈·옵션 단위로 비교하고, 선택 조합의 가격과 10×7m 사이트 배치를 검토한다. 쿠디, 에어노크, 캠빌을 주요 비교 대상으로 하며 추가 모델은 DB에 보존하되 자동으로 주요 후보에 넣지 않는다.

## 데이터 원칙

- 원본 PDF·엑셀·Markdown·HTML은 수정하지 않는다.
- 확인되지 않은 수치나 호환성을 추정하지 않는다.
- 원본 Claim과 현재 계산용 채택값을 분리한다.
- 충돌하는 새 정보는 기존 값을 덮어쓰지 않는다.
- 최종 총액은 기본가·교체금·옵션·세트 할인·배송비를 모두 확인했을 때만 표시한다.
- 도킹 호환성과 실제 사이트 설치 적합성을 분리한다.
- 건조 난이도는 평가하지 않는다.

## 시스템 구조

새 PDF 첨부·사용자 확인 → `db/catalog.sqlite`의 Claim·채택값·검증 대장 → DB에서 생성한 JSON → GitHub Pages 시뮬레이터 순서로 흐른다. `wiki/`는 결정의 맥락과 미해결 질문을 연결한다. 원본 PDF·엑셀·기존 HTML은 공개 저장소에 없으며 재검증 시 다시 제공받아야 한다.

## 현재 서비스

시뮬레이터는 GitHub Pages에서 PC 없이 사용할 수 있다. 시나리오는 브라우저별 로컬 저장소에 남으며 JSON 내보내기·가져오기로 공유한다. 검토한 위키 Markdown은 공개 GitHub 저장소에서 Codex Cloud의 작업 맥락으로 사용한다. Pages 산출물에는 포함하지 않는다.
