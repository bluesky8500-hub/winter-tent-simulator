# 에어노크 7.0T 알파미니

## 현재 종합

DB에는 비주요 비교 후보로 등록돼 있다. 43쪽 판매페이지 PDF를 2026-11-04에 재검증했다. PDF에서 직접 확인한 사실과 사용자가 확인한 가격·도킹 방향을 구분한다. 계산용 채택값은 아래 명시된 조건에서만 사용한다.

| 항목 | 현재 값 | 근거·상태 |
|---|---|---|
| 본체 판매가 | 580,000원 | PDF 1쪽 직접 표시, 채택 유지. 680,000원은 취소선 표시가 |
| 본체 배송비 | 15,000원 | PDF 1쪽 표시와 사용자 직접 확인, 채택 유지. 복수 텐트 합배송 조건 미확인 |
| 본체 외곽 | 300×230×190cm | PDF 12·30·32쪽. 30쪽 도면은 정면 190cm, 후면 170cm |
| 수납 크기 | 70×35×30cm | PDF 31쪽. 측정 오차 가능 문구 있음 |
| 스킨 | T/C 면 35%·폴리에스터 65% | PDF 28·32쪽 |
| 본체 바닥 | 410D 립스탑 PU 코팅 | PDF 32쪽. 유료 타포린 그라운드시트와 별개 |
| 에어폴 | PVC | PDF 32쪽 |
| 본체 중량 | 단일 확정값 없음 | PDF 2쪽 16.5kg / 13·32쪽 16.8kg 충돌 |

## 기본 포함품과 유료 옵션

PDF 2쪽의 기본 구성품 목록에는 본체·보관가방·펌프가 있다. 각 수량은 적혀 있지 않다. 31쪽 하단 그림에서 팩처럼 보이는 항목은 표기와 수량을 읽을 수 없어 포함 여부를 미확인으로 보존한다.

전용 커넥터 79,000원, 타포린 그라운드시트 79,000원, 전용 풀플라이 129,000원은 **사용자가 직접 확인한 채택 가격**이다. 이번 PDF에서는 각 단가를 직접 확인하지 못했다. 풀플라이는 기본 포함품이 아닌 유료 옵션이라는 점만 PDF 28~30쪽에서 확인된다. 다른 타프·TPU·메쉬 옵션의 가격과 중복 관계는 미확인이다.

## 도킹

- 10.0ST: **전면만** 도킹 가능, 전용 커넥터 필수 — 사용자 직접 확인.
- 10.0 타프쉘터: **전면·후면** 도킹 가능, 전용 커넥터 필수 — 사용자 직접 확인.
- PDF 18·20쪽에는 타프쉘터 사용 이미지가 있지만, 그 이미지에서 방향별 가능 범위를 새로 추정하지 않았다.
- PDF 24~25쪽은 10.0 M블랙 타프쉘터 기존형은 도어 구조 차이로 7.0T 도킹 불가, 개선형은 도킹용 지퍼가 추가됐다고 구분한다. 실제 판매 버전의 식별은 미확인이다.
- 커넥터의 실제 길이·겹침량과 도킹 완료 외곽은 미확인이다. 두 본체 치수를 단순 합산해 설치 가능으로 표시하지 않는다.

## 남은 확인

16.5kg과 16.8kg의 포함 범위, 팩 포함 여부와 구성품 수량, 옵션 가격의 판매페이지 직접 근거, M블랙 판매 버전, 복수 텐트 배송 조건, 도킹 완료 치수.
