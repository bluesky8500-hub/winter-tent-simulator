# 위키 변경 로그

## [2026-11-04] decision | 위키를 Codex Cloud 작업 맥락으로 공개 저장소에 보존

- 사용자 요청에 따라 검토한 Markdown 위키를 GitHub 개발 저장소에 포함한다. Pages 사이트에는 포함하지 않는다.
- `db/catalog.sqlite`가 계속 유일한 구조화 데이터 원본이다. 위키의 이전 수치가 DB와 다르면 DB와 출처를 다시 확인한다.
- 로컬에만 있던 원본 PDF·엑셀·기존 HTML과 백업은 업로드하지 않았다.
- 새 Cloud 작업이 이전 체크아웃에서 시작하는 사례가 있어, 작업 트리가 깨끗하고 fast-forward 가능한 경우에만 최신 `main`을 가져오는 시작 규칙을 최상위 `AGENTS.md`에 추가했다.

## [2026-11-04] ingest | 에어노크 7.0T PDF 검증과 DB 변경분을 위키에 반영

- 43쪽 PDF의 가격·치수·소재·중량 표기와 사용자 확인 옵션 가격·도킹 방향을 분리해 페이지를 만들었다.
- 16.5kg/16.8kg 중량 충돌, 기본 팩 포함 여부, M블랙 판매 버전, 옵션 가격 PDF 직접 근거의 미확인을 유지했다.
- 쿠디 8.0 PRO와 에어노크 7.0T 배송비가 DB에 채택된 상태로 쟁점 요약을 갱신했다.

- 8.0 PRO와 에어노크 추가 옵션의 세부 페이지는 아직 작성 대기다.
