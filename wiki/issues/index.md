# 충돌·미확인 대장

## 계산에 직접 영향

- PRO 공용 커넥터 현재 채택 가격: 62,000원. 59,000원 Claim은 비채택 이력
- 현재 DB의 9개 기본 패키지는 모두 배송비 채택값이 있다. 새로 확인된 쿠디 8.0 PRO 20,000원과 에어노크 7.0T 15,000원도 포함한다.
- 옵션 단독 구매 배송비, 에어노크 7.0T의 복수 텐트 공동 구매 배송비 합산·합배송 조건은 미확인
- 세트 할인: 적용할 확정 금액과 조건 없음

## 제품 사양과 구성

- [[coody-10-floor-material|쿠디 10.0 PRO 바닥 소재 적용 범위]]
- 캠빌 원단 혼용률은 면 35% / 폴리에스터 65%로 사용자 확인. 반대 Claim은 비채택 이력
- 에어노크 6.4 중량 18kg / 18.5kg
- [[../products/airnok-7-alpha-mini|에어노크 7.0T]] 중량 16.5kg / 16.8kg, 기본 팩 포함·수량, 옵션 가격의 PDF 직접 표기 여부
- 에어노크 7.0T와 M블랙 타프쉘터: 기존형은 도킹 불가, 개선형에는 도킹 지퍼가 있다. 일반형과 개선형의 판매 버전 식별은 미확인
- 해피패밀리 타프쉘터 정면 TPU는 기본 포함. 별도 129,000원 옵션의 적용 대상과 추가 구매 의미는 미확인으로 보존
- 해피패밀리 상품정보 49kg / 상세 구성 본체 30kg+25kg의 범위

## 조합과 설치

- [[../combinations/coody-10-hub-docking|10.0 PRO + 허브쉘터 PRO]] 명목 외곽은 계산했으나 설치 여유 미확인
- 모든 도킹 조합의 가이라인·차량·동선·팩다운 외곽
- 7.0T 도킹 완료 외곽과 커넥터 실제 치수·겹침량

현재 상태와 전체 검증 항목은 `db/catalog.sqlite`의 `verification`에서 확인한다. 이 목록은 탐색용 요약이며 DB의 행을 대체하지 않는다.
